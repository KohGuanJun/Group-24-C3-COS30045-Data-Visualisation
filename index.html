Glossary & Data Notes

Data Source

The dashboard uses 2011–2021 Australian road crash hospitalisation data from the Bureau of Infrastructure and Transport Research Economics (BITRE). See the BITRE release and its data dictionary.

Key Metrics

Hospitalised injuries. Recorded hospitalisation cases for road crash injuries. One person can account for more than one case.

Total bed days. Total days of admitted hospital care for the cases covered by the dataset.

Average bed days. Total bed days divided by total hospitalisation cases. This measures hospital care per case and can also reflect care practices.

Demographic Categories

Road user. The injured person's role in the crash, such as car driver, motorcyclist or pedestrian.

Remoteness. Based on usual residence. Regional includes Inner and Outer Regional. Remote includes Very Remote. The demographics data also has a Missing category.

Age and sex. Age is recorded at admission. Demographics shows 65–74 and 75+ separately. First Nations uses 65+. The sex chart retains the combined intersex, indeterminate or missing category.

Interpreting the Data

Comparing states. Raw counts show the number of cases. Compare per-person risk using population-based rates. Indexed mode compares each state with its own 2011 value.

Changes over time. The eight jurisdictions totalled 38,869 cases in 2019 and 37,292 in 2020, with increases in five jurisdictions. BITRE also flags changes in case inclusion in Victoria in 2012 and NSW in 2017.

Dataset coverage. The demographics file contains 410,884 cases and the state file totals 403,293. The project files do not identify the records behind the 7,591-case difference. First Nations breakdowns can also have different totals.

Dashboard Controls

Overview. Select a year or state to change the focus. The bed-days comparison and state share chart keep their own metrics when the Metric filter changes.

Demographics. Select a category to filter the other charts. When Average Bed Days is selected, the remoteness donut shows the share of hospitalisations.

First Nations. Select a year label or trend point to update the other charts. Click an age, remoteness or road-user mark to highlight it and show its trend. Use Reset to restore the default filters.
